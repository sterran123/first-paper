# AI와 함께 쓰는 첫 논문

**같은 글을 AI가 반복해서 고칠 때, 고치는 양은 줄어드는가**

한국어 짧은 글 10편에 같은 교정 지시를 AI가 3회 반복 적용했을 때, 회차별 변경률(편집 거리 비율)이 6.91% → 1.49% → 0.62%로 감소함을 확인한 소규모 실험 논문. 편집 범위를 제한한 대조 조건(조건 B)에서는 1차에서 완전 수렴(0%)을 확인했다.

**양식**: 국내 KCI 학술지 형식(국문초록·영문초록 병기, 서론–관련연구–방법–결과–고찰–결론)에 준해 작성했다.

## 파일 구조

- `paper.md` — 완성 논문 (표지·초록·서론·방법·결과·논의·참고문헌·재현 방법)
- `experiment-plan.md` — 실험 설계와 후보 주제 선정 과정
- `analysis.js` — 회차별 변경률 계산 스크립트 (`node analysis.js`)
- `data/samples/` — 입력 텍스트 10편 (원자료)
- `data/rounds/` — 회차별 교정 출력 30건 (원자료)
- `data/analysis.csv` — 샘플×회차별 편집 거리·변경률 측정값

## 재현

```bash
node analysis.js   # analysis.csv 갱신 + 회차별 평균 출력
```
